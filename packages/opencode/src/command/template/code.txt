Show the source code for a saved trading algorithm.

Input: $ARGUMENTS

## Instructions

If `$ARGUMENTS` is provided (an algorithm name):
1. Use the `finny_algorithm_get` tool with that name
2. Display the algorithm's code with syntax highlighting (use a python code block)
3. If the algorithm also has config or backtestCode, show those in separate code blocks
4. Show metadata: version, status, last updated

If `$ARGUMENTS` is empty:
1. Use the `finny_algorithm_list` tool to show all available algorithms
2. Ask the user which algorithm they'd like to view
3. Once they respond, use `finny_algorithm_get` to fetch and display it
